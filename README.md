## ⚡ Core Capabilities

### 1. 🔍 Domain Tech Stack Exposure Matrix (`[2]`)
Analyzes live HTTP response headers, DOM footprints, and JavaScript bundles to extract the **exact technology stack** powering any web target:
* **Web Servers**: Nginx, Apache HTTP Server, Microsoft IIS, LiteSpeed, Caddy, Gunicorn, Kestrel.
* **CMS & Builders**: WordPress, Shopify, Drupal, Ghost, Wix, Squarespace, Webflow, Joomla.
* **Frontend UI Frameworks**: React, Next.js (SSR), Vue.js, Nuxt.js, Angular, Svelte, jQuery, Tailwind CSS, Bootstrap.
* **Backend Runtimes**: PHP, Node.js, Python, Ruby on Rails, ASP.NET.
* **CDN & Edge Security**: Cloudflare, Cloudflare WAF, Vercel, Netlify, AWS CloudFront / S3, Azure Front Door, Fastly.
* **Analytics & E-Commerce**: Google Analytics (GA4), Meta Pixel, Shopify SDK, Stripe, PayPal.
* **Security Headers**: HSTS, Content Security Policy (CSP), Cloudflare Turnstile, reCAPTCHA.

### 2. 👤 Deep Username Persona & "Interesting Facts" Harvester (`[11]`)
Unlike basic status-code checkers, Resplicon queries structured JSON APIs and endpoints across **12+ major networks** to harvest a unified, verifiable dossier:
* **GitHub API**: Full name, geo-location, organization, bio, repository count, account creation date.
* **HackerNews API**: Karma score, submission history, profile about statement.
* **Dev.to API**: Bio, linked Twitter/GitHub accounts, joined date.
* **Keybase API**: Cryptographic PGP fingerprints, verified Twitter/Reddit/GitHub proofs, crypto public keys.
* **Multi-Platform Presence**: Steam, GitLab, Reddit, Telegram, Twitter, Medium, SoundCloud, Pinterest.
* **Synthesized Dossier**: Automatically correlates real names, employer entities, and timeline facts.

### 3. 🌐 Global Phone Tracking Engine (`[3]`)
* Formats and validates international phone numbers across **80+ countries** (`+1` to `+998`).
* Detects jurisdictional origin, capital, telecom carriers, and ISO country codes.
* Classifies line types: **Mobile**, **Fixed Landline**, or **VoIP / Virtual Burner**.

### 4. 🔗 Link-Based AI Slop & Synthetic Content Detector (`[A]`)
* Ingests any webpage URL or pasted text directly over HTTPS.
* Strips HTML boilerplate and extracts natural language sentences.
* Evaluates **sentence length burstiness**, **Type-Token Ratio (TTR)** vocabulary diversity, and recurrent LLM discourse markers (*"delve"*, *"testament to"*, *"in conclusion"*).
* Outputs a calibrated **AI Slop Index (0%–100%)** with factual authenticity grading.

### 5. 🎣 Hacking & Phishing Forensic Audits (`[H]`)
* **Typo-Squatting Detection**: Flags homoglyphs and impersonation of major brands (PayPal, Microsoft, Google, Steam, Chase, Binance).
* **Credential Harvesters**: Identifies fake login forms (`<input type="password">`) and exfiltration webhooks (Discord/Telegram).
* **Disposable TLD Risk**: Flags high-abuse top-level domains (`.xyz`, `.top`, `.click`, `.buzz`).
* **Backdoor IOC Probes**: Checks common malicious ports (Metasploit 4444, RDP 3389, Telnet 23, VNC 5900, unauthenticated Redis 6379).

### 6. 🪙 Sploken Token Economics & Hardware Memory
* Every operator starts with an allocation of **25,000 Splokens (`SPLOK`)**.
* Every scan, audit, or multi-agent hunt incurs a realistic deduction with a live transaction ledger.
* **Hardware Binding**: Profile is tied to the operator's machine signature and persists in `config/resplicon_device.json` across sessions.
* **Secret Codes**: Unlisted authorization codes allow operators to recharge their balance or elevate clearance to **Black-Ops Prime**.

### 7. 🌐 Interactive 2.5D Web Operations Deck (`[G]`)
* Launch a high-tech browser deck by passing `--web` or pressing `[G]`.
* Generates [`workspace.html`](workspace.html) featuring real-time CSS radar grids, agent status cards, and live audit telemetry.

## 🚀 Quick Start

### Prerequisites
* **Operating System**: Windows 7, 8, 10, or 11 (64-bit).
* **Runtime**: Built-in Microsoft .NET Framework 4.0/4.5/4.8 (pre-installed on virtually all modern Windows machines).
* **External Dependencies**: **Zero**. No Python, Node.js, or package managers required.

### 1. Launch the Operations Console
Simply run the included launcher or executable:
```cmd
run.cmd
```
*or directly:*
```cmd
Resplicon.exe
```

### 2. Autonomous Target Hunt (Single Target CLI)
Run the full 5-agent squad autonomously against any target:
```cmd
# Domain tech stack and infrastructure investigation
Resplicon.exe shopify.com

# Deep identity and facts discovery
Resplicon.exe torvalds

# Global international phone scan
Resplicon.exe +18005550199
```

### 3. Open the 2.5D Browser Command Deck
```cmd
Resplicon.exe --web
```

### 4. Render the Real-Time ASCII Floorplan
```cmd
Resplicon.exe --floorplan
```

### 5. Building from Source
If you modify the source code, rebuild the executable with the included build script:
```cmd
build.bat
```
*(Uses the native Windows C# compiler at `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`)*
